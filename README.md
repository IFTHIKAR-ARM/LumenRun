# Lumen Drift

✨ **Lumen Drift** — A relaxing HTML5 musical light & arcade survival game built for CrazyGames. Drift through a starlight sanctuary, collect harmonic light shards, unleash Nova shockwaves, customize your player profile & nickname, and upgrade your Solar Orb in Zen Chill or Classic mode with permanent local auto-save and CrazyGames cloud sync.
